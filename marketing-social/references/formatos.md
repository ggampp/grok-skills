# Formatos por plataforma

## Instagram — post único
- Preview = primeiras 125 caracteres
- Corpo 80–250 palavras no máximo para feed
- Ritmo de verso, não parágrafo de blog
- CTA no fim + hashtags em bloco separado

Skeleton:
```
[GANCHO]

[1–2 linhas de tensão]

[Desenvolvimento em blocos de 1–3 linhas]

[Prova ou exemplo]

[Takeaway]

[CTA]
```

## Instagram — carrossel
- 7–10 slides
- Slide 1 só o gancho (texto grande, fundo limpo)
- Um insight por slide
- Slide penúltimo = resumo
- Último = CTA + motivo de seguir / salvar

Texto de capa ≠ caption. Caption aprofunda e pede comentário.

## Reels / TikTok / Shorts
Duração alvo 15–35s para teste, 45–60s se a retenção aguentar.

Beat sheet:
1. 0–3s hook visual + frase
2. 3–8s identifica a dor
3. 8–20s método / virada
4. 20–30s prova rápida
5. Fecho CTA verbal + texto

Caption:
```
[gancho curto]
[1 linha de contexto]
[CTA]
[3–5 hashtags]
```

Direção: cortes a cada 1–2s no início, jump cuts, overlays de 3–5 palavras.

## LinkedIn
- Linha 1 e 2 decidem o "ver mais"
- 800–1.500 caracteres costuma performar melhor que textão
- História pessoal + princípio + aplicação
- Sem "estou feliz em anunciar" sem substância

Skeleton:
```
[Gancho concreto]

[Cena — o que aconteceu]

[O que eu errei / vi]

[Princípio]

[Como aplicar amanhã]

[Pergunta específica]
```

## X / Twitter
Tweet avulso: uma afirmação afiada.

Thread:
1. Promessa + "Thread"
2. Contexto em 1 tweet
3–7. Pontos isolados (cada um printável)
8. Recap
9. CTA de reply ou bookmark

Não comece a thread explicando quem você é.

## Stories
Sequência:
1. Hook frame (texto 6 palavras)
2–4. Desenvolvimento
5. Enquete ou caixa de pergunta
6. CTA / link / "responde X"

Uma ideia. Um sticker. Zero parágrafo.

## YouTube Shorts
Mesma lógica de Reels, mas o título/caption pode ser mais SEO ("como fazer X sem Y").

## Anúncio Meta / TikTok
Entregue pack:
- 3 hooks (3s)
- Primary text curto (primário) e médio
- Headlines 5–8 palavras
- Descrição
- CTA nativo da plataforma (Saiba mais, Cadastre-se, Comprar)
- Nota de compliance — o criativo não pode prometer o que a LP não entrega

Estruturas pagas que funcionam:
- Problem → agitation → solution → proof → offer
- UGC talking-head
- Demo rápido
- Antes / depois com ressalva honesta
- Testimonial com detalhe específico

## Mix semanal sugerido (orgânico)
- 40% ensino / método
- 25% opinião / tese
- 20% bastidor / prova
- 15% oferta ou conversão explícita
