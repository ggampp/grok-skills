# Frameworks de Humor para Memes Fortes

## 1. Setup + Punchline (Clássico)
- Top: expectativa / normal
- Bottom: subversão / real
Ex: Top "Quando o cliente diz 'é só uma mudança pequena'"  
Bottom "3 sprints e 47 reuniões depois"

## 2. Contraste Extremo
- Duas coisas que não deveriam coexistir
Ex: Animal + profissão séria, medieval + iPhone, CEO + caos total

## 3. Exagero de Emoção
- Expressão 10x maior que a situação
Surprised Pikachu, Woman Yelling, Mocking SpongeBob

## 4. Níveis de Escalação (Expanding Brain)
1. Versão normal / noob
2. Versão intermediária
3. Versão "inteligente"
4. Versão absurda / galaxy brain

## 5. Negação no Caos (This Is Fine)
Tudo queimando + personagem calmo dizendo que está tudo bem.

## 6. Preferência Absurda (Drake)
Rejeita algo perfeitamente normal / bom  
Aprova algo ridículo / preguiçoso / caótico

## 7. Dilema Infernal (Two Buttons)
Dois botões igualmente ruins / engraçados

## 8. Plano que se Auto-Destroi (Gru)
1. Ideia genial
2. Execução
3. Quase lá
4. "Peraí..."

## Regras de Ouro do Texto
- **Curto** > Longo (máx 8-10 palavras por linha)
- **Coloquial** e natural (especialmente em PT-BR)
- **Sem ponto final**
- **ALL CAPS** ou Title Case forte
- **Relatable first**
- Evite explicação. O formato + imagem já carrega o contexto.

## Tom Brasileiro (quando o user for BR)
- Use "pô", "mano", gírias naturais com cuidado
- Referências: futebol, café, atraso, WhatsApp, família, trabalho CLT, IA, SAP

## Anti-Patterns (Evite)
- Texto longo demais
- Explicar a piada
- Formato errado para o joke
- Humor ofensivo direcionado
- Baixo contraste / texto ilegível
- Meme genérico sem personalidade
