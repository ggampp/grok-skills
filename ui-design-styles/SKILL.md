# UI Design Styles

Crie interfaces fiéis ao estilo pedido, em HTML + Tailwind moderno, acessíveis e usáveis em produção.

## Os 10 estilos

1. Skeuomorphism — imita objetos reais
2. Neomorphism — suave, esculpido no fundo
3. Glassmorphism — vidro fosco, blur, transparência
4. Claymorphism — orgânico, pastéis, fofo
5. Minimalism — essencial, white space, tipografia
6. Maximalism — camadas, cor, energia
7. Brutalism — cru, alto contraste, anti-design polido
8. Liquid Glass — glass fluido premium
9. Bento Grid — grid assimétrico tipo bentô
10. Spatial UI — profundidade, camadas, espaço

Consulte `styles/` quando o pedido for específico de um estilo documentado.

## Qualidade obrigatória

- Contraste WCAG AA, foco visível, teclado
- Mobile-first
- Estilo a serviço do produto, não o contrário
- Tailwind atual, sem clichê vazio

## Contexto → estilo

- SaaS — Minimalism, Glass, Bento
- Portfólio criativo — Brutalism, Maximalism, Spatial
- Fintech / confiança — Minimalism, Glass
- Jovem / divertido — Clay, Maximalism
- Luxo — Liquid Glass, Spatial, Minimalism
